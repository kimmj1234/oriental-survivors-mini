# 뱀파이어 서바이벌 미니

원작(Vampire Survivors) 방식 그대로, **과제 조건과 충돌하는 부분만** 조정한 웹 미니게임입니다.
설치 없이 `index.html`만 열면 됩니다. 로그인·계정·외부 서버 없음.

## 원작과 같은 것
- 탑다운 시점, 이동만 직접 조작, 무기는 자동 공격
- 적 무리, 경험치 구슬 획득, 레벨업 시 카드 3장 중 1장 선택
- 무기 6종(부적·쿠나이·낫·도깨비불·향로·풍차 수리검), 능력 6종, 각 최대 Lv5 — 원작의 무기 구성(조준 발사·직선·포물선·공전·오라·부메랑)은 그대로이고 **동양풍 소재로 바꿨습니다**
- 회복 아이템, 정예 적, 보스, 시간이 갈수록 늘어나는 적

## 스킬과 맵
- **스킬 표**: 무기 6종의 피해·쿨다운·개수·관통·범위가 레벨별 표(`WSTAT`) 하나에서 나오고, 발사와 레벨업 카드 설명이 같은 표를 씁니다. 카드에는 아이콘과 `피해 11 → 13` 같은 변화가 표시됩니다.
- **HUD**: 무기 슬롯에 아이콘, 레벨 5칸, 쿨다운 가림막이 있고 능력은 아이콘과 레벨이 표시됩니다.
- **스킬 연출**: 부적·낫·수리검 궤적, 쿠나이 잔광, 도깨비불 잔상, 향로 회전 점선과 피해 파동, 타격 스파크. 풍차 수리검은 돌아오는 길에 한 번 더 맞힙니다. 연출은 **움직임 줄이기**를 켜면 모두 꺼집니다.
- **동양식 테마**: 무기는 부적·쿠나이·낫·도깨비불·향로·풍차 수리검, 능력은 인장·투구·호리병·나막신·태극·엽전, 회복은 복숭아, 경험치는 구슬입니다.
- **맵**: 숲·평지·묘지 세 지역이 노이즈로 섞이며 소나무·벚나무·대나무·괴석·비석·봉분·석등(불빛)·장승·홍살문·연못·디딤돌·흙 자국·꽃 등이 장식됩니다. 충돌은 없고 시작 지점 주변은 비워 둡니다.
- 이미지를 불러오지 못하면 도형 그리기로 자동 대체되어 게임은 계속 동작합니다.
- 다시 만들려면 `python tools/make_sprites.py` 다음 `python tools/build_assets.py`를 실행합니다.
- 제출문 ①에 "적 캐릭터는 무료(CC0) Ninja Adventure 에셋을 AI가 골라 가공했고, 주인공·아이템·맵 장식·바닥은 AI가 작성한 생성 스크립트로 만들었다"를 적어 주세요. 주인공 디자인 방향(참고 이미지 분위기)은 본인이 정한 일로 적을 수 있습니다.

## 보존 / 초기화
- **보존**: 최고 기록, 기록표(최근 200판), 난이도·음소거·움직임 줄이기 설정
- **초기화(새 판마다)**: 시간, 체력, 레벨, 경험치, 무기·능력, 적·투사체·구슬·입자, 처치 수, 효과 상태

## 짧은 확인 방법 (C30)
1. **어디로 가나요**: 이 페이지 하나.
2. **3단계**: Enter로 시작 → P를 10번 빠르게 누름 → R로 재시작.
3. **통과 시 보이는 것**: 패널 `키 입력 수신 10 / 상태 변화 반영 10`, 일시정지가 10번 토글되어 처음 상태, 재시작 후 시간 0:00·체력 100.
4. **안 될 때 보이는 것**: 수신과 반영 숫자가 다르거나, 일시정지 중 시간이 늘어남.

10분 연속 실행 검사: **B**를 누르면 자동 조작이 켜져 시작·레벨업 선택·재시작을 스스로 반복합니다. 10분 뒤 콘솔 오류와 조작 가능 여부를 확인하세요.

20회 기록표: 패널 `기록 CSV 저장`으로 점수·시간·실패 원인·난이도 값을 내려받을 수 있습니다.
