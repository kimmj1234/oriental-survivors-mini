규칙

  • 공격은 자동입니다. 이동만 합니다.

  • 123: 레벨업 카드 선택
  • B: 검사용 자동 조작

기록

최고 기록 없음
    짧은 확인 방법
    1. 어디로 가나요: 이 페이지 하나만 엽니다. 로그인 없음.
    2. 3단계: Enter로 시작 → P를 10번 빠르게 누름 → R로 재시작.
    3. 통과 시 보이는 것: 입력 수신 10, 반영 10, 일시정지가 10번 토글되어 원래 상태, 재시작 시 시간 0:00·체력 100.
    4. 안 될 때 보이는 것: 수신과 반영 숫자가 다르거나, 일시정지 중 시간이 늘어납니다.
